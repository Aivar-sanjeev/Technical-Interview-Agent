# Senior Backend / Platform Engineer

We are hiring a Senior Backend Engineer to own APIs, data stores, and reliability for our customer-facing product.

## Responsibilities
- Design and implement REST and event-driven services in Python or Go.
- Improve latency, throughput, and cost of critical paths (caching, DB tuning, async workers).
- Participate in on-call rotation; drive incident reviews and preventive fixes.
- Collaborate with frontend and product on API contracts and feature delivery.

## Requirements
- 5+ years building production backend systems.
- Strong SQL and data modeling; experience with PostgreSQL and Redis.
- Solid understanding of HTTP, auth (OAuth2/JWT), and idempotent API design.
- Experience with Docker and CI/CD; familiarity with Kubernetes is a plus.
- Excellent communication and mentoring skills.

## Nice to have
- Experience with message queues (Kafka, RabbitMQ) and saga patterns.
- Observability: OpenTelemetry, structured logging, SLOs.
